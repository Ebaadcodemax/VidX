# Fixture rights and provenance

M1 integration tests generate their media at runtime using FFmpeg's synthetic
`testsrc` and `sine` sources. No creator or third-party audiovisual material is
included. Generated test files live in the operating-system temporary directory
and are removed after each test.

Before adding any real sample, record the source, license or written permission,
permitted processing, and deletion status here. Never commit private creator media.
